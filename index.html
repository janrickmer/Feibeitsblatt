KI-Einstellungen

Für das KI-Feedback an die Schüler:innen nutzt der Server Ihren eigenen API-Schlüssel. Der Schlüssel wird nur auf dem Server gespeichert und nie an die Browser der Schüler:innen übertragen.

Groq betreibt offene Modelle (z. B. gpt-oss-120b, Llama 3.3 70B) auf eigener Hardware und antwortet sehr schnell. Schlüssel: console.groq.com → API Keys (kostenloses Konto, keine Kreditkarte).

Limits (bitte in der Groq-Konsole prüfen): je nach Modell etwa 30 Anfragen pro Minute und 1000 pro Tag, dazu Token-Tageslimits je Modell (z. B. etwa 200 000 Token pro Tag bei gpt-oss-120b). Jede Feedback-Anfrage einer Schülerin bzw. eines Schülers ist eine Anfrage; ist das Tageskontingent eines Modells erschöpft, weicht der Server automatisch auf das nächste Modell aus. Für ganze Klassen ist Groq deshalb die Vorgabe.

Datenschutz: Prüfen Sie die Datenschutzbedingungen von Groq, bevor Schülertexte gesendet werden.

OpenRouter bündelt viele Sprachmodelle hinter einer gemeinsamen API. Modelle mit dem Zusatz :free kosten nichts; dafür genügt ein kostenloses Konto mit API-Schlüssel (openrouter.ai → Keys).

Limits: Ohne Guthabenkauf gibt es nur 50 kostenlose Anfragen pro Tag für das ganze Konto – das reicht nicht für eine Klasse. Nach einem einmaligen Guthabenkauf von 10 US-$ sind es 1000 pro Tag.

Datenschutz: Die kostenlosen Modelle laufen bei Drittanbietern, die Eingaben protokollieren oder zum Training verwenden dürfen. Das muss im OpenRouter-Konto unter Settings → Privacy erlaubt sein, sonst antwortet die API „No endpoints found matching your data policy“.

Google Gemini über die Gemini-API mit eigenem Schlüssel aus Google AI Studio.

Limits: Das kostenlose Kontingent hat Minuten- und Tageslimits je Modell; für manche Schlüssel liegt das Tageslimit neuer Modelle bei 0. Der Server weicht dann auf ein anderes Modell aus.

Datenschutz und Bedingungen: Im kostenlosen Kontingent darf Google Eingaben zur Produktverbesserung nutzen und von Menschen prüfen lassen. Für Nutzer:innen im EWR gelten laut Google die Bedingungen der bezahlten Dienste; dafür verlangt Google ein hinterlegtes Abrechnungskonto. Ohne Abrechnungskonto kommt Gemini für Schulen in Deutschland daher nicht infrage.

Cerebras bietet offene Modelle (z. B. gpt-oss-120b) über eine OpenAI-kompatible Schnittstelle an. Schlüssel in der Cerebras-Cloud-Konsole.

Limits: Die Grenzen des kostenlosen Kontingents sind nicht offiziell bestätigt – bitte in der Konsole prüfen.

Datenschutz: Prüfen Sie die Datenschutzbedingungen von Cerebras, bevor Schülertexte gesendet werden.

Anderer Dienst mit OpenAI-kompatibler Chat-API (…/chat/completions), z. B. Mistral oder ein eigener Server. Basis-URL ohne Schrägstrich am Ende und mit https:// eintragen, z. B. https://api.mistral.ai/v1, und die Modell-ID angeben.

Datenschutz: Prüfen Sie die Bedingungen des Dienstes, bevor Schülertexte gesendet werden.

An die KI gehen nur die Aufgabenstellungen, Ihre Musterlösungen und die Antworttexte – keine Kürzel, Geburtsdaten oder Klassen. Der Server speichert davon nichts. Kein kostenloses Kontingent ist unbegrenzt: Alle Anbieter begrenzen Anfragen pro Minute und pro Tag.
